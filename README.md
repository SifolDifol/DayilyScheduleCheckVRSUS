# 📅 Мониторинг расписания преподавателя (DailyScheduleCheck)

Приложение для автоматического отслеживания изменений в расписании преподавателей ПВГУС с уведомлением на электронную почту.

## 🚀 Основные возможности:
* Парсинг расписания с сайта `lk.tolgas.ru`.
* Гибкая настройка периода (от 1 дня до нескольких недель).
* Фоновая проверка каждый час (с 05:00 до 18:00).
* Отправка красивых HTML-писем при изменении расписания.
* Удобный веб-интерфейс (Flask) для настройки всех параметров без лезния в код.
* Полная контейнеризация (Docker + Docker Compose).

## 🛠️ Технологии:
* Python 3.10
* Flask (веб-сервер)
* BeautifulSoup4 (парсинг HTML)
* smtplib (отправка почты)
* Docker & Docker Compose

2. Скачайте проект.
